# 천령당 天靈堂 · 사주명리 웹앱 (v9)

여덟 글자에 새겨진 하늘의 뜻을 읽는 사주명리 사이트. 정적 페이지(GitHub Pages)로 배포됩니다.

## 구성
- `index.html` — 화면 마크업 (홈·무료운세·5대 테마·인생설계서 신청·관리자)
- `styles.css` — 웹 스타일 (먹빛 + 금 + 주홍, 모바일 17~18px 본문)
- `book.css` — A4 책자(인생설계서) 스타일
- `engine.js` — 사주 계산 엔진 (입춘·절기·오자둔, 진태양시 보정, 음력 변환)
- `content.js` — 5대 테마 · 16개 세부 탭 정의와 공통 조각
- `content-general.js` / `content-love.js` / `content-marriage.js` / `content-baby.js` / `content-wealth.js` — 탭별 전용 챕터
- `book.js` / `book-more.js` — 88장+ 인생설계서 생성기 (표지·목차·원국·영역별·30년 대운·5년 세운·2027 월력·개운·Q&A·검수)
- `app.js` — 화면 동작 (오늘의 운세, 오늘의 타로, 테마/탭, 신청 4단계, 관리자 검수함)

## 주요 동작
- 오늘의 운세·오늘의 타로: 무료, 생년월일만으로 동작
- 5대 테마 16개 세부 탭: 탭마다 다른 챕터 구성 (임신운에는 아이 공부 내용 없음)
- 출생 지역 진태양시 보정: 시주(時柱) 계산에 분 단위 반영, 결과에 보정 내역 표시
- 관리자: 상단 `관리자` 버튼 또는 `?admin=1`, `?book=sample`로 샘플 책자 확인 후 인쇄/PDF 저장
