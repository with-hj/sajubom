# 월하당 · 동양풍 사주 웹앱 시안

모바일 우선 단일 페이지 사주 웹앱 프로토타입입니다.

- `index.html` — 앱 전체 (HTML/CSS/JS 단일 파일)
- `assets/character-main.png` — 월하당 캐릭터 일러스트
- `assets/bg-pattern.png` — 동양풍 배경 패턴
- `assets/og-image.png` — 카카오톡·SNS 공유 카드 (1200×630)
- `assets/icon.png` — 파비콘·애플 터치 아이콘 (180×180)
- `assets/themes-web/` — 5대 테마 일러스트 웹 최적화본 (배너 900px · 썸네일 240px)

## 5대 테마 · 세부 탭

| 테마 | 세부 탭 |
|---|---|
| 종합운세 (總) | 신년운세 · 평생사주 · 오늘의 운세 · 대운 흐름 |
| 썸·연애·재회 (緣) | 썸 속마음 · 재회/연락운 · 내 연애 패턴 |
| 궁합·결혼·이혼 (婚) | 커플 궁합 · 결혼 시기/배우자 · 부부 갈등/이혼수 |
| 임신·자녀 (孕) | 임신/출산 타이밍 · 아이 기질/적성 · 부모와의 합 |
| 재물·직업 (財) | 재물/투자운 · 이직/퇴사 타이밍 · 창업/부업 적성 |

유료 풀 리포트는 6개 장(내면·오행개운·연애·재물·건강·대운)으로 구성되며, 선택한 테마·세부 탭에 따라 장 순서·중심 장·인트로·장별 맞춤 문단이 달라집니다. 상대 생년월일을 넣으면 궁합 참고 지수 카드가 붙고, 신년운세·오늘의 운세 탭에는 각각 세운 카드와 오늘 일진 카드가 표시됩니다.
