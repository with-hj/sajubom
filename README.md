# 월하당 · 동양풍 사주 웹앱 (v8)

모바일 우선 단일 페이지 사주 웹앱입니다. `index.html` 하나에 화면·스타일·계산 엔진이 모두 들어 있습니다.

- `index.html` — 앱 전체 (HTML/CSS/JS 단일 파일)
- `assets/character-main.png` — 월하당 캐릭터 일러스트
- `assets/bg-pattern.png` — 동양풍 배경 패턴
- `assets/og-image.png` — 카카오톡·SNS 공유 카드 (1200×630)
- `assets/icon.png` — 파비콘·애플 터치 아이콘 (180×180)
- `assets/themes-web/` — 5대 테마 일러스트 웹 최적화본 (배너 900px · 썸네일 240px)

## 두 갈래 탭

상단 전환기로 두 트랙을 오갑니다.

| 트랙 | 내용 |
|---|---|
| **바로 보는 · 5대 테마 운세** | 종합운세 · 썸·연애·재회 · 궁합·결혼·이혼 · 임신·자녀 · 재물·직업 (16개 세부 탭) |
| **깊이 보는 · 📜 인생설계 PDF** | 30년 사주 전문가 인생설계서 신청 (4단계 → 미리보기 잠금 → 접수 → 관리자 검수·발송) |

## 1트랙 — 5대 테마

| 테마 | 세부 탭 |
|---|---|
| 종합운세 (總) | 신년운세 · 평생사주 · 오늘의 운세 · 대운 흐름 |
| 썸·연애·재회 (緣) | 썸 속마음 · 재회/연락운 · 내 연애 패턴 |
| 궁합·결혼·이혼 (婚) | 커플 궁합 · 결혼 시기/배우자 · 부부 갈등/이혼수 |
| 임신·자녀 (孕) | 임신/출산 타이밍 · 아이 기질/적성 · 부모와의 합 |
| 재물·직업 (財) | 재물/투자운 · 이직/퇴사 타이밍 · 창업/부업 적성 |

- 생년월일은 `[년][월][일]` 3칸 입력, 본문은 모바일에서 읽기 좋은 큰 글씨.
- **지금 상황(선택)** — 결혼·연애 상태 / 자녀 유무 / 직업 형태를 고르면, 리포트 서두에 전제를 밝히고
  장마다 "지금 자리" 해설이 붙습니다. 미혼·무자녀인데 배우자·자녀가 있는 것처럼 읽히지 않습니다.
- 각 장 끝에 **30년 시선** 문단(대운 지도 기준)이 붙어 장의 깊이를 보강합니다.

## 2트랙 — 인생설계 PDF 신청

1. **1/4 원국 정보** — 이름·성별·음양력·3칸 생년월일·태어난 시간. 입력하면 `띠 · 만 나이 · 음/양력 변환 · 일주`가 바로 계산됩니다.
2. **2/4 지금의 자리** — 결혼 상태(미혼·연애중·기혼·돌싱), 자녀(없음·있음·준비중), 직업(직장인·사업·프리랜서·취준·학생·주부).
3. **3/4 받으실 곳** — 휴대폰·이메일(검증 포함).
4. **4/4 질문·동의** — 직접 묻고 싶은 질문 300자 + 필수 동의 2 + 확인 카드.
5. **미리보기 잠금** — 2027년 핵심 3줄(가장 잘 풀리는 달·돈이 들어오는 달·전환점)이 블러로 가려진 채 표시되고, 패키지 3종을 고릅니다.
   - 인생설계 풀패키지 39,800원 / +2027 신년운세 54,900원 / +신년운세+궁합·자녀 69,900원
6. **접수 완료** — 주문번호와 함께 접수 화면. 주문은 이 브라우저 `localStorage`(`wlh_orders_v1`)에만 저장됩니다(테스트).

### 관리자 검수함

- 여는 방법: 2트랙 하단 **관리자 검수함** 링크, 또는 `?admin=1`.
- 접수 목록 + 실제감 있는 샘플 주문 1건이 기본으로 들어 있습니다.
- 주문을 누르면 **A4 책자형 리포트(18면)** 가 열립니다.
  표지(테마 아트) → 목차·읽는 순서 → 만세력 표(십성·12운성·오행·음양) + 오행 막대 → 14장 본문 → 검수·발송.
  14장: 30년을 여는 문 / 타고난 그릇 / 오행과 용신 / 십성 구조 / 성격과 사람 사이 / 재물 / 일과 자리 /
  인연과 결혼 / 자녀와 가족 / 건강과 체질 / 30년 대운 지도 / 2027년 세운·12개월 달력 / 개운 처방 / 질문 답변.
  결혼·자녀·직업 상태에 따라 해당 장의 서술이 달라집니다.
- **📄 PDF 인쇄 / 저장 (A4 책자형)** — `@media print`로 A4 한 장에 한 챕터씩, 머리글·바닥글·페이지 번호 포함.
- **✉️ 검수 완료 · 발송 처리** — 상태를 `발송 완료`로 바꾸고, 메일·카톡용 발송 문구를 복사할 수 있게 만듭니다.

## 검증

- 16개 세부 탭 × 상대 유무 = 32조합 리포트 생성 검사, 한글 6,500자 이상·8장 이상
- 책자 18면 고정, 4개 생년월일 × 문장 검사(`undefined`/`NaN`/조사 오류 없음)
- 4단계 신청 → 접수 → 관리자 → 인쇄 → 발송 전 과정 브라우저 자동 검사
