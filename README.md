## 화면 구조 (v19)
- 밤하늘 대문: 「달빛 아래, 당신의 여덟 글자 / 궁금한 물음 하나로 나의 계절을 읽다 / 다섯 가지 주제 중 하나를 고르면, 그 자리에서 여덟 글자를 펼쳐 읽어드립니다」
- 5대 테마 일러스트 카드(종합운세·썸연애재회·궁합결혼이혼·임신자녀·재물직업) + 선택 테마 대형 일러스트 배너 + 금빛 알약 세부 탭
- 상단 트랙(2개, 2줄 표기): `3,900원 · 테마별 풀이 / 운세 보기` · `프리미엄 평생 사주 / 인생사주 리포트`
- 인생사주 리포트 랜딩 5단계: 표지(평생 여정 아트 + 제목 + 바로 신청) → 상품 소개 → 리포트 구성(8장) → 미리보기(실제 3장) → 구매 안내(가격·제공·제작·개인정보·환불) + 신청 폼

## 구성
- `index.html` — 화면 마크업 (홈·5대 테마·인생사주 리포트 신청·관리자)
- `styles.css` — 웹 스타일 (밤하늘 남색 + 금 + 모래빛 시트, 모바일 17~18px 본문)
- `book.css` — A4 책자(인생사주 리포트) 스타일
- `engine.js` — 사주 계산 엔진 (입춘·절기·오자둔, 진태양시 보정, 음력 변환)
- `content.js` — 5대 테마 · 15개 세부 탭 정의와 공통 조각
- `content-general.js` / `content-love.js` / `content-marriage.js` / `content-baby.js` / `content-wealth.js` — 탭별 전용 챕터
- `content-deep.js` — 모든 탭 뒤에 붙는 심화 장(일주·오행·개운·10년·평생·몸·사람·실천). 탭마다 조합이 달라 한 편이 9,000~11,000자가 됨
- `assets/themes-web/` — 5대 테마 일러스트 (배너 `general/love/marriage/baby/wealth.jpg`, 카드 `t-*.jpg`)
- `assets/cover-art.jpg` — PDF 표지 (사주봄 대문 아트)
- `assets/life-report-hero.jpg` — 인생사주 리포트 랜딩 표지 (평생 여정 캐릭터 · 남색 밤하늘)
- `assets/preview/` — 미리보기 3장 (총평·평생 대운·12개월)
- `book.js` / `book-more.js` — 인생사주 리포트 생성기 (표지·목차·원국·영역별·평생 대운 9구간·5년 세운·12개월 월력·개운·Q&A·검수·서른 날의 실천). 104쪽, 본문 15.5px 기반 자동 맞춤(장마다 A4 한 장에 맞춰 미세 조정), 푸터는 흐름 배치라 본문과 겹치지 않음, 목차 줄을 누르면 해당 장으로 이동
- `app.js` — 화면 동작 (테마/탭, 탭별 입력 항목, 2장 무료 미리보기 + 흐림 결제 게이트, 신청 4단계, 관리자 검수함)

## 주요 동작
- 테마 풀이(3,900원): 원국 요약 + 1~2장은 무료 공개, 3장부터는 첫 문장만 또렷하게 두고 나머지 문장을 실제 글자 그대로 흐리게(블러) 보여 준다 + 「결제 후 전체 보기」 카드. 인생사주 리포트는 정가 99,000원 → 23,800원(76% 할인), 테마 결제 후 업셀 19,900원. 결제는 포트원 V2(KG이니시스 테스트 채널)
- 5대 테마 15개 세부 탭: 탭마다 다른 챕터 구성. 임신·자녀는 `임신·출산운` · `자녀 사주` · `엄마·아빠 궁합` 3탭
- 탭별 맞춤 입력: 현재 상황(직업) 칩은 종합운세·재물직업에, 결혼 상태는 연애·결혼·임신출산·엄마아빠궁합에, 자녀 칩은 종합운세·임신출산운에만 보임. 자녀 사주 탭은 부모 사주 + 아이 정보만 받음
- 출생 지역: 지역별 보정은 내부에서만 적용하고 화면에는 분 단위 표기를 노출하지 않음. `출생지 모름` 선택 가능
- 관리자: 상단 `관리자` 버튼 또는 `?admin=1`, `?book=sample`로 샘플 책자 확인 후 인쇄/PDF 저장
